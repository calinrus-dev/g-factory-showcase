# Origen y límites

Fecha de la muestra: 2026-10-02.

`gfactory/plan.py` es el primer contrato de dominio implementado para G Factory. Se publica una copia seleccionada de ese componente, sus pruebas y un manifiesto ficticio. No es un exportador ni una implementación pública del producto entero.

`assets/g-factory.svg` es una lámina de identidad diseñada para este showcase. No es una captura de una aplicación existente. No contiene interfaces de cuentas ni medios de terceros.

Las pruebas verifican duraciones, orden, rangos, tipos numéricos y errores CLI. No procesan medios, no llaman modelos, no publican contenido y no acreditan persistencia, concurrencia o calidad audiovisual.

No se incluyen credenciales, datos personales de colaboradores, grabaciones ni configuración privada. Publicación por selección explícita; no espejo automático del repositorio privado.
